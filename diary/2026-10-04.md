#### Lambda decisions and thought process
1. Each service provider used (e.g., Aviation Weather Center, Met Eireann) will have their own corresponding function. Further splitting, for example by service (METAR, TAF, ISIGMET) results in a lot of repeated code (blocks for HTTP GET requests, HTTP headers S3 PUTs).
2. Lambda functions will not be placed in a VPC for now. I know from my Cloud Computing module last semester that the costs associated with running a NAT gateway in AWS are significant, regardless of traffic volume. We are still ~9 months away from the end of FYP.
3. I will use EventBridge Scheduler to invoke the required function through passing arguments to the event via JSON. This is a middle ground between one-function-per-service and a monolith. 
4. I will set up one IAM execution role per service, i.e., both METAR and TAF will get their own execution role.
